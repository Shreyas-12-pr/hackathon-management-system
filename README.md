# Hackathon Management System

A production-grade Hackathon Management System (HMS) for managing the complete hackathon lifecycle.

## Technology Stack

- Next.js
- TypeScript
- FastAPI
- Python
- PostgreSQL
- Redis
- Docker
- GitHub Actions
- Terraform
- OpenTelemetry
